# Torre de Hanói

A implementação do clássico problema da Torre de Hanói, utilizando recursão para mover discos entre três torres seguindo regras específicas.

## Descrição

O problema da Torre de Hanói é um quebra-cabeça matemático que consiste em três torres e um número de discos de diferentes tamanhos que podem ser empilhados em qualquer uma dessas torres. O objetivo do quebra-cabeça é mover toda a pilha para outra torre, obedecendo às seguintes regras:

1. Apenas um disco pode ser movido por vez.
2. Cada movimento consiste em pegar o disco do topo de uma das pilhas e colocá-lo no topo de outra pilha.
3. Um disco maior não pode ser colocado sobre um disco menor.
